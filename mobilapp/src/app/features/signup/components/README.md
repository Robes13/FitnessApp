# Signup – komponenter

| Mappe              | Indhold                                                           |
| ------------------ | ----------------------------------------------------------------- |
| `signup-progress/` | Fremdriften øverst på siden: ring, kapitelnavn og kapitelbjælker. |
| `steps/`           | De 14 trin. Ét trin pr. mappe, selector `app-<trin>-step`.        |

Komponenterne her er feature-specifikke. Genbrugelige byggeklodser (knapper, kort, lineal,
figur …) ligger i `shared/components/` og må ikke kopieres herind.
