# HomeWeekCard

"Seneste 7 dage" (`app-home-week-card`): dage i mål, kcal i snit, protein ramt og streak i et
2×2-gitter plus en kort opsamling nederst. Kun dage med poster tæller med. Før madloggen og målet
er hentet, står der `–`, og opsamlingen er skjult (tom `note`). Input `summary` fra
`HomeSummaryService.weekSummary()`.
