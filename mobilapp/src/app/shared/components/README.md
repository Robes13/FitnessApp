# Shared components

Systemets UI-byggeklodser. Hver komponent har sin egen mappe med `README.md`, hvor API og
særlige beslutninger står. Tabellen herunder er indekset – **tilføj en række, når du laver en
ny komponent**.

| Komponent                                              | Selector                                    | Formål                                                                                                                                                                                                        |
| ------------------------------------------------------ | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`UiButton`](ui-button/README.md)                      | `button[app-ui-button]`, `a[app-ui-button]` | Designets pille-knap: `primary` / `outline` / `surface` / `outline-danger` / `ghost` / `danger` / `subtle`, fire højder, `pill`/`rounded`, `block`, `loading`.                                                |
| [`UiIconButton`](ui-icon-button/README.md)             | `button[app-ui-icon-button]`                | Den runde `.circ`-knap til ét ikon. Otte størrelser (56–26 px), seks toner. Kræver `aria-label`.                                                                                                              |
| [`UiIcon`](ui-icon/README.md)                          | `app-ui-icon`                               | Stroke-ikon fra `icon-registry.ts` (de ikoner, appen viser), ni størrelser (12–64 px).                                                                                                                        |
| [`UiTextInput`](ui-text-input/README.md)               | `app-ui-text-input`                         | Glas-inputfelt med `ControlValueAccessor`, indbygget øje på adgangskoder, `translucent`/`centered`-varianter, `invalid` i rød eller orange.                                                                   |
| [`UiFormError`](ui-form-error/README.md)               | `app-ui-form-error`                         | Hint-/fejllinje under et felt med reserveret højde og `role="status"`.                                                                                                                                        |
| [`UiChip`](ui-chip/README.md)                          | `button[app-ui-chip]`                       | Filter-/valg-chip, `selected`, to højder, valgfrit `filled`.                                                                                                                                                  |
| [`UiSwitch`](ui-switch/README.md)                      | `app-ui-switch`                             | Skydeknap 48×28, styret: `checked` ind, `checkedChange` ud.                                                                                                                                                   |
| [`UiSegmentedControl`](ui-segmented-control/README.md) | `app-ui-segmented-control`                  | Radiogruppe som pille med glidende knop eller kompakte faner. Generisk i værdi-typen.                                                                                                                         |
| [`UiTabBar`](ui-tab-bar/README.md)                     | `app-ui-tab-bar`                            | Bundnavigationen med fem celler og glidende orange knop, styret af routeren.                                                                                                                                  |
| [`UiProgressBar`](ui-progress-bar/README.md)           | `app-ui-progress-bar`                       | Vandret fremdriftsbjælke 4/6 px i fem toner + `inverse`, animeret bredde.                                                                                                                                     |
| [`UiProgressRing`](ui-progress-ring/README.md)         | `app-ui-progress-ring`                      | Cirkulær fremdriftsring (dagsringe, kaloriering, trin-tæller) med projiceret midte.                                                                                                                           |
| [`UiCard`](ui-card/README.md)                          | `app-ui-card`                               | Standardkort: glas-fyld og hairline; `soft` og orange `accent`-gradient.                                                                                                                                      |
| [`UiRowButton`](ui-row-button/README.md)               | `button[app-ui-row-button]`                 | Række med label, værdi og chevron (Profil, opsummering); `regular`/`compact`.                                                                                                                                 |
| [`UiSheet`](ui-sheet/README.md)                        | `app-ui-sheet`                              | Bundark med scrim, titel + orange accent, slots (også over titlen), fire maksimumhøjder, `column`-krop, lagorden, Escape/scrim-luk.                                                                           |
| [`UiEmptyState`](ui-empty-state/README.md)             | `app-ui-empty-state`                        | Tom tilstand: stiplet boks med forklarende tekst; `default`/`subtle` og to tekststørrelser.                                                                                                                   |
| [`UiSpinner`](ui-spinner/README.md)                    | `app-ui-spinner`                            | Roterende ring (`dcspin`), tre størrelser, `accent`/`current` tone.                                                                                                                                           |
| [`UiPageHeader`](ui-page-header/README.md)             | `app-ui-page-header`                        | Sidehoved med tilbage-knap, centreret caption-titel og `[headerAction]`-slot.                                                                                                                                 |
| [`UiOptionCard`](ui-option-card/README.md)             | `button[app-ui-option-card]`                | Valgkort med label/beskrivelse, blå eller orange valgt-stil, radio-prik, række- eller kolonnelayout, `regular`/`compact` højde.                                                                               |
| [`UiRuler`](ui-ruler/README.md)                        | `app-ui-ruler`                              | Lineal-slider med træk, tastatur og glød om den aktuelle værdi (`glowReach` / `glowStrength`).                                                                                                                |
| [`Figure`](figure/README.md)                           | `app-figure`, `g[app-figure-body]`          | Maskotten: geometri fra vægt/højde/humør, krop som SVG-del, færdig SVG med loft/lampe og `bandToneForGender()`.                                                                                               |
| [`ProfileAvatar`](profile-avatar/README.md)            | `app-profile-avatar`                        | Brugerens avatar: beskåret profilbillede eller blå cirkel med forbogstavet. Fire størrelser + beskæringsformlerne i `photo-crop.ts`.                                                                          |
| [`FoodPicker`](food-picker/README.md)                  | `app-food-picker`                           | Vare-vælgeren fra "Tilføj mad": søg → portion eller ny egen vare. Tom tilstand, typed form med API'ets lofter, skalerede makroer og `busy`.                                                                   |
| [`BarcodeScanner`](barcode-scanner/README.md)          | `app-barcode-scanner`                       | Stregkodescanner: kamera (native) eller indtastet stregkode (browser), opslag med loading/fejl/"ikke fundet" og resultat-ark med justerbar mængde. Domænelogikken ligger i core-facaden `BarcodeFlowService`. |
| [`UiConfirmSheet`](ui-confirm-sheet/README.md)         | `app-ui-confirm-sheet`                      | Bekræftelse før sletning (vare, samling): ikke-lukbart ark med rød bekræft-knap og "Annuller", tekster som nøgler, `busy`.                                                                                    |
